# CareerTrellis Brand Workshop

## Selected working name

**CareerTrellis**

**Positioning line:** *Find, tailor, track, and prepare—on your terms.*

CareerTrellis describes a flexible support structure for a job search without implying that the product submits applications. It can grow beyond discovery and materials into interviews, networking, career evidence, and long-term career management while keeping the job seeker in control.

## Name workshop

| Candidate | Strength | Decision |
| --- | --- | --- |
| **CareerTrellis** | Memorable growth metaphor, broad enough for the full workflow, and truthful about user control | Selected working name |
| Career Workbench | Clear and practical | Finalist, but descriptive and difficult to distinguish or protect |
| Opportunity Desk | Broad and approachable | Finalist, but less clearly connected to careers and job search |
| [JobLoom](https://www.jobloom.tech/) | Strong organization metaphor | Rejected; an active job-search product already uses it |
| [RoleCraft](https://role-craft.pl/) | Communicates deliberate preparation | Rejected; active career-strategy and interview services use it |
| RoleFoundry | Strong creation metaphor | Rejected; an active career-content brand uses it |
| [RoleTrail](https://roletrail.com/) | Suggests progress tracking | Rejected; active software already uses it |
| [Job Search Studio](https://jobuble.com/) | Immediately understandable | Rejected; generic and already used by competing products as a product/category label |

The preliminary screen was performed on 2026-08-08 using exact-name web searches and DNS resolution. No obvious competing job-search product named CareerTrellis was found. `careertrellis.com` resolved at the time of the check; `careertrellis.app` and `careertrellis.io` did not resolve. DNS results do not establish registration availability, ownership rights, or freedom to use a mark.

## Voice and product promises

- Say **guided manual application**, **AI-assisted**, and **you stay in control**.
- Do not promise automatic application submission, guaranteed interviews, guaranteed offers, or an authoritative ATS score.
- Lead with user ownership, truthful materials, local privacy, and a complete search-to-interview workspace.
- Use **CareerTrellis** as one word with capital C and T.

## Pre-launch clearance

Before public launch, obtain a professional trademark search in intended markets, check relevant corporate names and app stores, confirm domain and social-handle ownership through authoritative registrars/platforms, and secure the chosen properties. The [USPTO trademark search](https://tmsearch.uspto.gov/) and [ICANN registration lookup](https://lookup.icann.org/en) are starting points, not substitutes for professional clearance. Then decide whether to rename the GitHub repository and legacy technical identifiers. The current repository name, database filename, environment variables, and dependency stamps remain unchanged so existing local installations continue to work.
